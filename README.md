# STARmeter / The Great Dive

A browser-based shot authoring tool for the STARmeter scroll sequence. The three opening people—the main actor and the two surrounding cards—can each have their name, credits, rank, and portrait replaced locally. The move can be timed and previewed before exporting the finished shot.

## Local development

```sh
npm install
npm run dev
```

GitHub Pages builds and publishes the production site automatically from `main`.
