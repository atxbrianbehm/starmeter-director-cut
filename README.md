# STARmeter / The Great Dive

A browser-based shot authoring tool for the STARmeter scroll sequence. The three opening people and two ending people can each have their name, credits, rank, and portrait replaced locally. Shot length is explicitly adjustable in frames (default 81 frames / 3.375 seconds), and the frame-addressed H.264 MP4 export preserves that exact duration at 24fps.

## Local development

```sh
npm install
npm run dev
```

GitHub Pages builds and publishes the production site automatically from `main`.
